# UI Theme Reference

This folder holds the **FreeDash-lite** HTML/SCSS theme used as a design reference for SnapStock-AI.

The React app does **not** import these files at runtime. Styles are reimplemented in:

- `src/index.css` (tokens)
- `src/components/dashboard/DashboardLayout.tsx`
- `src/pages/dashboard/DashboardHome.tsx`
- `src/components/ui/card.tsx`

Primary accent in SnapStock is **green** (`#1d6b45`) instead of FreeDash blue (`#5f76e8`).
